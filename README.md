## Rakitra
- `index.html` – ny app manontolo
- `sw.js` – service worker (miasa tsy misy aterineto). Ovay ny `V` rehefa manova kinova.
- `manifest.webmanifest` + `icons/` – ho an'ny fametrahana ao amin'ny findainao
- `vercel.json` – fanamboarana ho an'ny Vercel
- `FAMPIASANA.txt` – torolàlana momba ny fampiasana
